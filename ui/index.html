Who are the influencers?

Two ways to measure importance. Friends (degree) just counts connections. PageRank (the algorithm behind Google) also asks who you are connected to: a friend who is important themself counts more. Click any user to see them in the graph.

Top 15 by number of friends

Degree centrality: share of all other users who are their friends.

Top 15 by PageRank

1.0 = an average user. ◆ both = also in the other top 15.

Friends vs PageRank, every user

Each dot is a user. Both axes are logarithmic (1, 10, 100, …). Dots high above the crowd have few friends but important ones.

Which groups of friends exist?

Label Propagation: every user starts with their own label and repeatedly takes the label most common among their friends. Groups emerge by themselves. Modularity checks the result: how much more connected the groups are inside than chance would give (above 0.3 = clear groups).

How it works

Every number on this page was computed by Spark jobs on a cluster of laptops. The data lives in HDFS, stored twice on different laptops. This page only displays the results.

Pipeline

Each step is one Spark job (jobs/), reading from and writing to HDFS.
Raw dataSNAP edge list in HDFS /sna/raw
→
01 Build graphclean, both directions, GraphFrame
→
02 Statisticsdegrees, triangles, clustering, components
→
03 Influencersdegree centrality, PageRank
→
04 CommunitiesLabel Propagation, modularity
→
05 Recommendmutual friends + Adamic-Adar
→
06 Exportresults + layout → this page

The cluster

Three laptops on one phone hotspot; they find each other automatically (registry).
Master laptopSpark master + driver, 1 worker
HDFS NameNode + DataNode
registry
Friend laptop ASpark worker
HDFS DataNode
Friend laptop BSpark worker
HDFS DataNode

Fault tolerance (tested): a job still finishes when a worker leaves mid-run, and every file stays readable when a laptop's storage leaves. HDFS then restores the 2 copies itself.

Run time of the whole pipeline

Measured 22 Nov 2026 (README, section 6.5). Same results on every setup.

More laptops = slower here: this graph is small, and a phone hotspot is ~400× slower than the network inside one laptop. Distribution pays off for big data.
